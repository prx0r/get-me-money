## Key architecture decisions

1. **ONE execution path** — loop.py is canonical. No parallel executors.
2. **Judge gets config** — real Hermes evaluation, not fallback heuristic.
3. **Workspace isolation** — each candidate gets own directory.
4. **Cost accounting** — every Hermes call tracked in CandidateRecord.
5. **Bounded counts** — max 5 candidates, max 3 revisions. LLM can't exceed.
6. **Validation** — invalid JobSpec falls back, never silently proceeds.
7. **submitted ≠ accepted** — only external outcome creates economic success.
8. **Apify is the ONE real adapter** — contract tested against live API.
9. **Feature freeze** — no new modules until PR-H lands.
