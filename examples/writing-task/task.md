# Write a Technical Blog Post: "Why x402 Changes Everything for AI Agents"

Write a 1500-2000 word blog post explaining x402 micropayments and why they matter for AI agents.

## Requirements

1. **Target audience** — technical but non-expert (engineers curious about agent payments)
2. **Structure** — hook → problem → solution → how it works → implications → conclusion
3. **Specific examples** — at least 2 concrete use cases with code snippets or diagrams
4. **Sources** — cite at least 3 external references
5. **Tone** — authoritative but accessible, not salesy

## Scoring

- Clarity: 30% — can a reader understand x402 after reading
- Technical accuracy: 25% — correct description of how x402 works
- Engagement: 25% — compelling writing, good hooks, interesting examples
- Completeness: 20% — covers the topic thoroughly

## Rejection

- Under 1500 words
- No code examples or diagrams
- No sources cited
- Technically inaccurate
- Reads like a product advertisement
