# Build an x402 Payment Demo

Create a working demonstration of x402 micropayments between two AI agents.

## Requirements

1. **Working code** — TypeScript or Python, runnable with `npm install && npm start` or `pip install -r requirements.txt && python main.py`
2. **Two agents** — Agent A offers a service, Agent B pays for it via x402
3. **Payment flow** — show the full flow: request → price quote → payment → delivery → confirmation
4. **README.md** — clear setup instructions, architecture diagram, what each file does
5. **Tests** — at least one test that verifies the payment flow works

## Scoring

- Functionality: 40% — does it actually work
- Code Quality: 25% — clean, readable, well-structured
- Documentation: 20% — README is clear and complete
- Innovation: 15% — creative use of x402 or interesting service

## Rejection

- Does not run without errors
- No README
- No tests
- Payment flow is mocked/faked (must use real x402 protocol)
- Missing architecture explanation
